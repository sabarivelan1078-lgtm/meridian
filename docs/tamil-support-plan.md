# Tamil Support Plan

## Language strategy
The app should be English-first with Tamil support. This matches the learner's preference and the Band 8 goal: practice must develop English thinking, while Tamil should clarify difficult mistakes and reduce confusion.

## Supported modes

### English-first with Tamil support
Default mode. Feedback is mostly English, with Tamil explanations for important grammar, vocabulary, and pronunciation issues.

### English only
Optional mode for test-like practice and mock tests.

### Tamil support boost
Optional mode for difficult lessons where the learner wants more Tamil explanation.

## Where Tamil should appear
- Grammar explanations.
- Vocabulary meanings.
- Common mistake explanations.
- Pronunciation guidance.
- Strategy reminders.
- Encouraging coach notes.

## Where Tamil should be limited
- Actual speaking answers.
- Timed mock tests.
- Band 8 model answers.
- IELTS question prompts, except optional translation hints.

## Example grammar explanation
Mistake:

```text
I am having two brothers.
```

Correction:

```text
I have two brothers.
```

Tamil support:

```text
தமிழில் "எனக்கு இரண்டு சகோதரர்கள் இருக்கிறார்கள்" என்று சொல்வதால் English-ல் "I am having" என்று சொல்ல வேண்டும் போல தோன்றலாம். ஆனால் family அல்லது possession பற்றி பேசும்போது "I have" என்பதே இயல்பான English.
```

## Tamil learner error patterns to track

### Grammar
- Missing articles: a, an, the.
- Subject-verb agreement.
- Singular and plural endings.
- Tense consistency.
- Preposition errors.
- Direct Tamil-to-English sentence structure.
- Overuse of present continuous.
- Incorrect stative verb usage.

### Vocabulary
- Direct translation from Tamil.
- Repeating simple words.
- Limited collocations.
- Unnatural formal words in casual answers.
- Memorized phrases that do not fit the question.

### Pronunciation
- Final consonant clarity.
- Plural and third-person -s endings.
- Past tense -ed endings.
- /v/ and /w/ distinction.
- /z/ sound.
- Consonant clusters.
- Word stress.
- Sentence rhythm.

## Tamil explanations in feedback
Each feedback item should be concise:
1. State the mistake in English.
2. Give the correction.
3. Explain the reason simply.
4. Add Tamil only when it helps.
5. Give one speaking practice sentence.

## Test readiness rule
During mock tests, Tamil should not interrupt the test. Tamil explanations should appear only after the test is complete.
